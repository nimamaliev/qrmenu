# QRMenu website

Marketing website for **QRMenu**: QR-code digital menus for restaurants, with
3D models of dishes and an analytics dashboard for owners.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4.
